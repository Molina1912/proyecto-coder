# TECH CONNECT | Desarrollo web y soluciones tecnológicas

Este repositorio contiene el código fuente del sitio web oficial de TECH CONNECT, empresa dedicada a ofrecer servicios de desarrollo web, consultoría tecnológica y soporte especializado para impulsar la transformación digital de negocios.

## Descripción

TECH CONNECT brinda soluciones tecnológicas personalizadas para empresas y emprendedores, enfocándose en innovación, calidad y acompañamiento profesional. El sitio web presenta información sobre los servicios, portafolio de proyectos y canales de contacto.

## Tecnologías utilizadas

- HTML5
- CSS3 (con Bootstrap 5)
